# Discours — Règles d'écriture

## Principes fondamentaux
Un discours est un acte de performance orale. Il n'est pas lu — il est incarné.
Chaque phrase doit pouvoir être dite à voix haute sans accroc.
Le silence est un outil autant que les mots.

## Structure classique d'un discours

### Ouverture (3-5% du temps)
- Capter l'attention sans introduction générique.
- Trois approches possibles :
  - Anecdote personnelle forte liée au sujet
  - Question rhétorique qui met le public face à lui-même
  - Affirmation puissante ou paradoxe
- Ne jamais commencer par "Je suis heureux d'être ici" ou "Merci de m'avoir invité".

### Mise en contexte (10-15%)
- Établir pourquoi ce sujet compte maintenant.
- Nommer le problème ou l'enjeu collectif.
- Créer un sentiment de reconnaissance dans le public.

### Corps principal (60-70%)
- Maximum 3 à 5 idées clés. Pas plus.
- Chaque idée : énoncé clair → illustration concrète → signification profonde.
- Rythme : alterner les registres (logique, émotion, exemple, données, histoire).
- Retour au fil conducteur toutes les 3-4 minutes.

### Climax / Moment fort (10-15%)
- Le point de bascule. Ce qui rend le discours mémorable.
- Peut être une révélation, une vision, un appel à la transformation.
- Doit provoquer une émotion forte : espoir, détermination, empathie.

### Conclusion (5-10%)
- Boucler avec l'ouverture (reprendre l'anecdote ou la question initiale).
- Formuler l'appel à l'action ou la vision.
- Dernière phrase = ce que le public emporte.

## Techniques oratoires à intégrer

### Tricolon (série de 3)
"Nous avons bâti, nous avons cru, nous avons réussi."
Les séries de 3 sont mémorables et créent un rythme naturel.

### Répétition intentionnelle (anaphore)
"Ce n'est pas une question de talent. Ce n'est pas une question de chance. C'est une question de choix."

### Question rhétorique
Poser une question sans attendre de réponse crée un moment de réflexion collective.

### Pause après les mots forts
Indiquer dans le script : [PAUSE] après chaque affirmation forte.

## Marqueurs oraux
- Indiquer les emphases : mots en MAJUSCULES ou entre *astérisques*
- Indiquer les pauses : [PAUSE], [RESPIRATION]
- Indiquer le rythme : [PLUS LENTEMENT], [ÉLEVER LA VOIX]

## Erreurs à éviter
- Phrases trop longues (impossibles à dire en un souffle)
- Jargon technique sans définition
- Manque de fil conducteur (liste de points déconnectés)
- Conclusion qui s'effiloche au lieu de percuter
- Discours écrit pour être lu plutôt que prononcé
