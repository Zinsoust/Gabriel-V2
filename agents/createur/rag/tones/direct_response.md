# Tonalité Direct Response — Guide d'écriture

## Principe
Le direct response a un seul objectif mesurable : déclencher une action précise maintenant.
Chaque mot est là pour rapprocher le lecteur du clic, de l'achat, de l'inscription.

## Règles fondamentales du direct response

### Règle 1 : Clarté absolue
Le lecteur ne doit jamais se demander ce qu'on lui propose, à qui c'est destiné, ce qu'il doit faire.
→ Message > Créativité.

### Règle 2 : Bénéfice avant tout
On ne parle pas du produit. On parle de ce que le produit change dans la vie du lecteur.
→ Pas "Formation en copywriting" mais "Écrire des textes qui se vendent."

### Règle 3 : Un seul CTA
Une seule action demandée par message. Plusieurs CTA = aucun CTA.
→ Choisir et n'en mettre qu'un.

### Règle 4 : Urgence réelle ou perçue
Sans urgence, la décision est remise à plus tard. Et plus tard = jamais.
→ Délai, place limitée, offre exclusive, prix temporaire.

### Règle 5 : Supprimer le risque
La principale barrière à l'action est le risque perçu.
→ Garanties, essai gratuit, témoignages, preuve sociale.

## Structure du message direct response

### Titre : Ce que tu obtiens / Ce que ça change
- Clair, direct, spécifique.
- Inclut le bénéfice principal.

### Corps : Pourquoi agir maintenant
- Problème (1-2 phrases)
- Solution (1-2 phrases)
- Preuve rapide (1-2 phrases)
- Offre précise (1-2 phrases)
- Urgence / Rareté (1 phrase)

### CTA : L'action unique
- Verbe d'action + bénéfice
- "Je veux [bénéfice]", "Accéder à [offre]", "Commencer maintenant"

## Formules éprouvées

### AIDA (Attention → Intérêt → Désir → Action)
Attention : hook fort
Intérêt : développer le problème ou le désir
Désir : montrer la transformation possible
Action : CTA clair

### PAS (Problème → Agitation → Solution)
Nommer le problème → amplifier la douleur → présenter la solution comme évidence

### FAB (Fonctionnalité → Avantage → Bénéfice)
Ce que c'est → Ce que ça fait → Ce que ça change pour toi

## Ce qui paralyse le direct response
- Trop d'options
- CTA vague
- Prix présenté avant la valeur
- Pas de preuve sociale
- Pas d'urgence
- Message trop long pour le canal
